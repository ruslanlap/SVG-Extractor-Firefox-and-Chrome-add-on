## 🚀 Швидке встановлення

Це Chrome-версія розширення SVG Extractor Pro з підтримкою Manifest V3.

### Крок 1: Завантажте папку

Завантажте всю папку `chrome-version` на свій комп'ютер або склонуйте репозиторій.

### Крок 2: Відкрийте сторінку розширень Chrome

1. Відкрийте Google Chrome
2. В адресному рядку введіть: `chrome://extensions/` і натисніть Enter
3. Або через меню: ⋮ (три крапки) → Розширення → Керувати розширеннями

### Крок 3: Увімкніть режим розробника

У правому верхньому куті сторінки розширень знайдіть перемикач **"Режим розробника"** (Developer mode) і увімкніть його.

### Крок 4: Завантажте розширення

1. Після увімкнення режиму розробника з'являться нові кнопки
2. Натисніть кнопку **"Завантажити розпаковане розширення"** (Load unpacked)
3. У вікні, що відкрилося, виберіть папку `chrome-version`
4. Натисніть "Вибрати папку" або "Select Folder"

### Крок 5: Готово! 🎉

Розширення встановлено! Тепер ви побачите іконку SVG Extractor Pro на панелі інструментів Chrome.

## 📖 Як користуватися

1. **Перейдіть на будь-який сайт** з SVG-зображеннями
2. **Натисніть на іконку розширення** на панелі інструментів
3. **Відкриється нова вкладка** з результатами пошуку
4. **Виберіть дію**:
   - 💾 Завантажити окремий SVG
   - 📋 Скопіювати SVG код
   - 🖼️ Зберегти як PNG

## ❓ Часті запитання

### Чому потрібен "Режим розробника"?

Chrome дозволяє встановлювати розпаковані розширення тільки в режимі розробника. Це безпечно і не впливає на роботу браузера.

### Чи безпечно це розширення?

Так! Ви можете переглянути весь вихідний код. Розширення не має доступу до ваших особистих даних і працює тільки на тих сторінках, які ви відкриваєте.

### Чому розширення не працює на деяких сторінках?

Chrome не дозволяє розширенням працювати на внутрішніх сторінках браузера (chrome://, chrome-extension://, chrome://settings/ тощо). Це обмеження безпеки браузера.

### Як оновити розширення?

1. Перейдіть на `chrome://extensions/`
2. Знайдіть SVG Extractor Pro
3. Натисніть кнопку оновлення (🔄) на картці розширення
